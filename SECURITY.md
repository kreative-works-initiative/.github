# Security Policy
 
## Reporting a vulnerability
 
If you believe you have found a security vulnerability in any Kreative Works Initiative project, **please do not open a public issue.**
 
Instead, use GitHub's **"Report a vulnerability"** button in the **Security** tab of the affected repository (private vulnerability reporting) and include the following details:

- A description of the issue and its potential impact.
- Steps to reproduce the issue or a proof of concept.
- The affected project and version.

## What to expect
 
- We will acknowledge your report as soon as we can.
- We will keep you informed while we investigate and fix the issue.
- We ask that you give us a reasonable amount of time to resolve the problem before any public disclosure.
- With your consent, we will gladly credit you once the fix is released.

## Supported versions
 
KWI projects are in early development. Security fixes are generally applied to the latest release only, unless a repository states otherwise.
